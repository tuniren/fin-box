# AI 分析使用说明

AI 分析是 FinBox 的可选辅助功能。该功能不会默认开启，也不会自动分析任何股票；只有在用户显式开启后，才会在个股详情页显示“AI分析”按钮，并由用户手动触发。

## 功能原理

FinBox 不内置大模型服务。触发 AI 分析时，FinBox 会把当前个股的行情、持仓、日 K、分时、可选笔记、可选资讯和可选讨论整理为一次性的结构化数据快照，然后调用本机已经安装并可用的 Codex 工具生成分析文本。

调用过程由 Electron 主进程执行，渲染页面不会直接执行系统命令。FinBox 会以只读、非交互方式调用 Codex，并要求输出条件化分析，不允许把结果表述为确定性预测。

## 使用前提

使用该功能前，需要本机至少满足以下条件之一：

- 已安装并登录可用的 Codex CLI；
- 已安装包含 Codex 可执行文件的 OpenAI / ChatGPT VS Code 插件；
- 已安装包含 Codex 可执行文件的兼容编辑器插件，例如 Cursor 或 Windsurf 的 OpenAI / ChatGPT 插件；
- 能够提供一个可执行的 `codex.exe` 完整路径。

如果 FinBox 提示找不到 Codex，可在“设置 > AI分析 > Codex命令”中填写完整路径，例如：

```text
C:\Users\<用户名>\.vscode\extensions\openai.chatgpt-<版本>-win32-x64\bin\windows-x86_64\codex.exe
```

如果从终端运行 `codex --version` 可用，但从 FinBox 中不可用，通常是因为桌面启动的 Electron 进程没有继承终端中的 `PATH`。此时填写完整 `codex.exe` 路径最稳定。

## 开启方式

1. 打开 FinBox。
2. 进入“设置 > AI分析”。
3. 开启“启用AI分析”。
4. 确认“Codex命令”可用。默认值为 `codex`。
5. 根据需要调整超时时间，以及是否附带个股笔记、资讯和讨论。
6. 打开任意个股详情页。
7. 点击“AI分析”。

## 数据范围

默认传给 Codex 的数据包括：

- 个股代码、名称、标签和别名；
- 当前行情快照，包括最新价、涨跌额、涨跌幅、开盘价、最高价、最低价、昨收价和行情时间；
- 当前持仓，包括总股数、市值、当日盈亏、累计盈亏、收益率和分账户持仓；
- 最近日 K 数据；
- 最近分时数据；
- 可选的个股笔记；
- 可选的最新资讯；
- 可选的讨论内容。

资讯和讨论默认关闭，因为这些内容通常噪声较高，且会增加分析耗时。

## 结果边界

AI 分析结果仅用于辅助复盘，不构成投资建议。应特别注意以下限制：

- AI 无法保证行情、新闻和讨论内容完整；
- AI 输出可能包含错误推断；
- AI 不会替用户执行交易；
- AI 不应被视为买入、卖出或持仓的唯一依据；
- 如果输入数据不足，结果应以“等待确认”或“观望”为主。

## 常见错误

### spawn codex ENOENT

含义：FinBox 找不到 `codex` 可执行文件。

处理方式：

- 在终端执行 `where codex`，找到 `codex.exe` 的完整路径；
- 将完整路径填入“设置 > AI分析 > Codex命令”；
- 重启 FinBox 后再次尝试。

### Codex exited with code ...

含义：Codex 已启动，但运行失败。

处理方式：

- 确认 Codex 已登录；
- 在终端中单独运行 `codex --version`；
- 检查网络和账户状态；
- 适当调高 AI 分析超时时间。

### AI analysis timed out

含义：分析超过设置的超时时间。

处理方式：

- 将超时时间调高，例如 `120000`；
- 关闭“附带最新资讯”和“附带讨论”；
- 稍后重试。
