# 固定 Transformer 代码页术语表

## `transformer.cpp`

自选工作台编辑区的固定代码标签。它永远位于第一个标签位置，默认激活，不允许关闭。

## 配置目录代码文件

指存储在应用配置目录下的 `camouflage/transformer.cpp` 文件。该文件不放入仓库，不随应用版本覆盖用户本地内容。

## 懒创建

当 `camouflage/transformer.cpp` 不存在时，主进程在首次读取时自动创建默认 C++ 示例代码。默认代码通过中文注释说明 Transformer 的核心原理。这样可以避免安装或升级时主动改写用户目录。

## 只读展示

代码页只展示语法高亮内容，不提供编辑输入。这样可以保持单界面高亮效果，并避免在未引入完整编辑器内核时产生输入、光标和滚动同步问题。

## 轻量 C++ 高亮

编辑区中的只读渲染结果。它对预处理指令、关键字、类型、字符串、数字、注释和操作符做词法着色，但不是完整 C++ 语言服务器或编译器前端。

## 自选工作台三栏

只有自选工作台保留左侧自选树、中间编辑区、右侧详情辅助栏。持仓、7X24、请求日志、使用说明和设置均为单页路由。
