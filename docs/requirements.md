# 项目需求文档 (Requirements)

## 1. 项目概述
创建一个基于 Rust 的原生桌面悬浮窗应用 (FinBox)，用于实时监控自选股票价格，并提供多账户持仓盈亏计算功能。应用追求极简、低资源占用和无干扰体验。

## 2. 技术栈
- **编程语言**: Rust
- **GUI 框架**: eframe (基于 egui)
- **网络请求**: reqwest (blocking)
- **配置管理**: serde, serde_yaml
- **系统路径**: directories
- **其他依赖**: chrono (时间处理), encoding_rs (GBK 解码)

## 3. 功能需求清单

### 3.1 第一阶段：基础框架 (已完成)
- [x] **极简外观**: 窗口尺寸小巧 (约 240x28)，无边框 (`decorations: false`)。
- [x] **窗口层级**: 永远置顶 (`always_on_top`)。
- [x] **透明背景**: 支持背景透明和圆角渲染。
- [x] **中文支持**: 加载系统字体 (Microsoft YaHei) 解决乱码。
- [x] **交互体验**: 全窗口拖拽，无标题栏。
- [x] **基础行情**: 对接新浪财经 API 获取实时股价。
- [x] **智能刷新**: 交易时间 (5s) 与休市时间 (60s) 自动切换刷新频率。
- [x] **基础显示**: 显示股票名称和当前价格。

### 3.2 第二阶段：高级功能 (已完成)
- [x] **多股支持**: 支持配置多个自选股票。
- [x] **复杂持仓配置**: 单只股票支持多条持仓记录。
- [x] **盈亏计算体系**: 支持单股当日/累计盈亏及账户整体盈亏。
- [x] **交互升级**: 点击图标展开详情，动态调整窗口高度。
- [x] **配置持久化**: 采用 YAML 格式存储于用户目录，支持热重载。
- [x] **界面优化**: 展开后列表展示，支持窗口动态尺寸调整。
- [x] **快捷操作**: 界面支持强制刷新、打开配置文件。

### 3.3 第三阶段：交互增强 (已完成)
- [x] **显示模式切换**:
    - 默认显示系统日期时间 (格式: 02-29 20:13 星期x)。
    - 点击中间文字区域可切换为显示盈亏信息 (<总盈亏>|<今日盈亏>)。
- [x] **右键菜单**:
    - 在程序主界面右键唤出菜单 (嵌入式悬浮层)。
    - **打开配置**: 快速打开配置文件所在的文件夹/文件。
    - **退出程序**: 安全退出应用。
- [x] **视觉与交互优化**:
    - 鼠标悬浮背景显示抓手图标，提示可拖拽。
    - 字体跨平台自适应 (Windows/macOS/Linux)。
    - 橙色高亮关键按钮与文本。
    - 盈亏颜色区分 (红涨绿跌)。

## 4. 目录结构规划
- `src/main.rs`: 程序入口，窗口配置。
- `src/app.rs`: UI 渲染层（主窗口 + 详情页 + 右键菜单）。
- `src/core.rs`: 核心业务逻辑（行情刷新、数据聚合）。
- `src/config.rs`: 配置定义与加载逻辑。
- `src/model.rs`: 数据模型（Stock, Position, Account）。
