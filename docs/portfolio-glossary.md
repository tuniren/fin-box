# 持仓管理术语表

## 持仓明细

单只股票在一个或多个账户中的数量与成本记录。数据来源为 `stocks[].positions[]`。

字段含义：

- `account`：账户名称，可为空。
- `shares`：持股数量；0 股记录允许存在，用于观察、清仓后保留或待恢复跟踪。
- `cost`：单股成本。

## 当前有效价格

用于计算持仓市值的价格。优先使用当前价；当前价不可用或为 0 时使用昨收价。

## 持仓金额

单只股票的当前市值。

公式：

```text
持仓金额 = 持仓股数合计 * 当前有效价格
```

如果持股数量为 0，则持仓金额为 0。若持股数量非 0 但行情不可用，则显示为 `--`。

## 成本金额

单只股票所有账户持仓成本的合计。

公式：

```text
成本金额 = Σ(账户持股数量 * 账户单股成本)
```

## 持仓占比

单只股票相对于账户总投入的暴露比例。

公式：

```text
持仓占比 = 单股持仓金额 / total_investment
```

`total_investment` 为空或小于等于 0 时，持仓占比显示为 `--`。

## 仓位

在统一持仓视图中，仓位用于表达账户层面的股票总暴露。

公式：

```text
总仓位 = 全部股票持仓金额合计 / total_investment
```

表格中的“仓位”排序与单股持仓占比使用同一数值，即 `单股持仓金额 / total_investment`；页面摘要中的“总仓位”是账户级指标。

## 标签包含任一

多标签过滤使用 OR 逻辑。选择多个标签时，只要某只股票包含其中任意一个标签，即进入结果集。

## 0 股股票

0 股股票仍属于持仓管理视图的展示范围。其用途包括保留观察标的、记录已清仓股票、维护别名和标签，以及等待重新建仓。
