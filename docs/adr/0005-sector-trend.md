# 0005 个股所属板块走势

## 状态

首版已实现，待用户验收。

## 已确认需求

- 新增个股所属板块的走势查看能力，交互参考同花顺 App。
- 用户以“比亚迪—汽车整车板块”为需求示例；实际行业名称遵循腾讯返回的分类，详见接口验证。
- 本需求中的“板块走势”与软件版本历史无关。
- 用户指定从腾讯个股详情页面使用的接口获取板块归属。
- 首版仅包含行业板块，不包含概念、地域板块。
- 同一个股对应多个行业板块时，支持切换查看。
- 行业板块当前值可显示在个股股价附近，用户可控制是否展示。
- 支持在自选浮窗和伪装浮窗展示行业涨跌幅数值，默认关闭，按股票开启。

## 已确认的展示与配置决策

- 每只股票保存当前选中的行业板块，避免切换股票后丢失选择。
- 主界面和浮窗使用该股票相同的板块选择，分别提供显示开关。
- 默认选择最细一级行业；用户手动选择后记忆其选择。
- 股价附近、浮窗及详情行情摘要仅展示行业涨跌幅的百分比数值，例如 `+0.65`，保留正负号及两位小数，不展示名称和百分号；配置选择控件仍保留行业名称。取值使用 `change_percent`，不使用指数点位 `price`，也不再乘以 100。
- 个股涨跌幅在左、板块涨跌幅在右，同一行显示；板块复用个股涨跌幅的字体、字号、字重及数字样式。自选浮窗同时复用涨跌颜色配置，浮窗宽度测量包含两个数值和间距。
- 用户要求尽量减少腾讯接口调用，将请求量作为实现约束。
- 自选浮窗配置页提供板块总显示开关，以及逐股票的浮窗显示开关和行业选择；行业选择与详情共享，配置页本身不查询归属或订阅行情。
- 总开关保存为 `watch_float.show_industry`，仅控制自选浮窗，不影响伪装浮窗和主界面。旧配置缺少该字段时视为开启，以兼容已有逐股票显示开关；默认股票显示开关仍关闭。
- 板块行情跟随全局股价刷新配置及现有行情调度，不设置固定 60 秒周期或其他独立节流周期。
- 行业归属查询结果直接保存至本地选股配置文件中对应的股票条目；仅在每日首次打开该股票详情页时更新。

## 每日详情页更新规则

- 按股票及北京时间自然日判断首次打开。每天第一次打开某股票详情页时触发一次归属查询；同日重复打开、切换返回或重启不再次查询。
- 首次查询成功后将腾讯行业列表、当前选择与更新日期写入现有本地选股配置；本版来源固定为腾讯，正常展示直接读取该配置。
- 为避免失败后反复打开触发请求，另保存当天查询尝试日期；失败保留原归属，不在同日自动重复查询。成功日期与尝试日期不能混用。
- 多窗口同时打开同一股票详情页时，仅发出一次查询。
- 不因行情刷新、浮窗打开、配置加载或自然日跨日主动查询归属；跨日后仍等待该股票详情页首次打开。
- 浮窗只消费已保存的归属。未打开过详情页且没有本地归属时显示缺失状态，不擅自查询。
- 归属查询成功但列表为空时也记录结果及日期；网络失败不能覆盖为无行业。
- 写回时基于最新配置合并该股票字段，保留持仓、标签和其他配置，避免异步请求完成时覆盖期间发生的用户修改。

## 低请求量设计

现有项目由主进程维护状态并向窗口广播，浮窗通过 `onState` 接收状态。新增行业板块能力应复用此机制，不能由各窗口分别轮询。

刷新频率和归属持久化遵循上述用户决策；其余故障处理为实现建议。以下策略尚未实现，也不代表腾讯允许的调用额度：

| 数据或场景 | 建议策略 |
| --- | --- |
| 股票所属行业 | 每日首次打开该股票详情页时查询并写入本地选股配置；其余场景直接读取配置 |
| 未找到行业 | 成功响应但无行业时记录当天空结果；次日首次打开详情页再查，网络错误保留旧结果 |
| 行业涨跌幅 | 仅刷新实际展示的行业，按来源及行业 ID 共享缓存；参与全局股价刷新轮次，间隔使用 `trading_refresh_interval_ms`，不另设固定 60 秒缓存 |
| 多窗口、多股票共用行业 | 相同行业共用行情；同一个资源的并发请求共用一个进行中的 Promise |
| 走势序列 | 首版采用当日分时，仅在视图可见时请求，跟随全局行情刷新；分时响应自带行情快照，直接复用以省去该行业的额外行情请求 |
| 无可见使用者 | 停止相应资源的定时刷新；窗口关闭、隐藏或股票切换后释放订阅 |
| 午休、收盘、非交易日 | 复用股价行情现有时段调度与刷新策略，不新增独立板块定时器 |
| 手动刷新 | 跟随现有行情刷新流程，复用正在进行的同资源请求；不得触发额外归属查询 |
| 轮次去重 | 每轮按行业 ID 去重；同资源上一轮请求未完成时不重复启动，不堆积补跑；初始订阅用 25 毫秒一次性合并，正常行情不额外限速；多个行业合并为一个请求，每批最多 80 个 |
| 请求失败、429 或服务异常 | 保留最后成功数据并标注更新时间；按 1、5、15 分钟逐步退避，尊重 Retry-After，不循环立即重试 |

关键约束：

- `plateNew` 同时返回归属和涨跌幅，但不能为了更新涨跌幅而按股票反复查询归属。
- 已验证行业行情接口与 `plateNew` ID 的对应关系；行情直接按行业查询，不按股票轮询详情接口。
- 不预取整份自选列表的全部行业、全部层级或全部历史周期。
- 本地选股配置持久化保存归属及更新日期。行情与分时仅缓存在主进程内存，行情时间和本地获取时间分开记录；重启后只加载实际展示的行业行情。
- 重启不能触发配置内所有股票重新查询归属；当天查询尝试日期持久化，确保同日重启不重复查询。行情故障退避状态仅保留在当前进程。
- 仅有本机缓存时无法承诺全体安装用户的总请求量；以上约束作用于单个应用实例。
- 实现验收需覆盖多窗口共享、同板块跨股票去重、无订阅停更及错误退避，并通过请求计数确认没有重复调用。

## 腾讯接口验证（2026-11-03）

从腾讯官方个股详情页面 `https://gu.qq.com/sz002594` 加载的脚本 `https://st.gtimg.com/quotes/hs-fund/bundle.13362df9.js` 中定位到板块请求，并通过 Node.js fetch 实测以下接口成功返回 `code: 0`：

```text
https://proxy.finance.qq.com/ifzqgtimg/appstock/app/stockinfo/plateNew?code=sz002594&app=wzq&zdf=1
```

- `data.plate`：行业板块，含 `code`、`id`、`level`、`name`、`zdf`。
- `data.concept`：概念板块，含 `id`、`name`、`tag`、`zdf`。
- `data.area`：地域板块，含 `id`、`name`、`zdf`。
- 比亚迪行业样本：`01801880 / 汽车 / level=1`、`01801095 / 乘用车 / level=2`。
- 比亚迪概念样本：`02101383 / 汽车整车概念`。不能将此概念静默改标为行业。
- `zdf` 是字符串形式的涨跌幅快照；该响应没有历史走势序列，也没有独立行情时间戳。
- 老接口 `/stock/relate/data/plate?code=sz002594` 也能响应，但返回另一套代码及分类结构，不能与 `plateNew` 的 ID 混用。
- 这是页面实际使用的接口，尚未取得稳定性承诺或正式协议文档；当前仅验证了 A 股样本。

已通过实际功能代码验证下列请求，行业 ID 与 `plateNew` 一致，均加 `pt` 前缀：

```text
https://qt.gtimg.cn/q=pt01801095,pt01801880
https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=pt01801095
```

行情文本按 GBK 解码；报价字段下标 3、4、30、32 分别为当前指数、昨收、行情时间和涨跌幅。分时响应的 `data.pt<ID>.data` 提供日期及时间序列，`qt.pt<ID>` 提供同一响应中的行情快照。

## 当前项目基础

- 已存在个股分时与 K 线组件，以及主进程行情获取和 IPC 入口。
- 新增 `sectors.ts` 管理腾讯行业归属、行情批量请求、分时、去重及错误退避；不依赖渲染进程定时器。
- 个股详情新增行业选择与分时入口，自选列表及股价摘要按开关展示板块信息；两类浮窗共享相同选择。

## 配置兼容

旧配置无需迁移；首次打开详情后新增 `stocks[].industry`。首次使用时两个显示开关默认关闭，避免未经用户选择就在伪装浮窗显示行业名称。

```yaml
industry:
  sectors:
    - id: '01801095'
      name: 乘用车
      level: 2
  selected_id: '01801095'
  attempted_on: '2026-11-03'
  updated_on: '2026-11-03'
  show_near_price: false
  show_in_float: false
```

## 验证

- `npm run test:sectors`：覆盖每日首次查询、重启复用、异步配置合并、查询失败保留旧值、批量及并发去重、刷新间隔调整、错误退避、腾讯响应解析、YAML 配置往返兼容。
- `npm run test:sectors:ui`：隐藏 Electron 窗口、隔离测试数据、禁用真实 HTTP 请求，验证行业切换、显示开关、自选列表、分时画布与两类浮窗。

- 有限次数的真实请求验证：比亚迪返回“汽车／乘用车”，批量报价和分时均能通过实际解析代码读取。

## 后续范围

历史 K 线、个股与行业叠加对比、成分股列表及非 A 股行业归属不在首版范围内。

## 设计原则

- 板块归属与板块行情是两类数据，需分别定义来源和更新机制。
- 同一股票可以关联多个板块；行业和概念须明确区分。
- 不以成分股涨跌幅的简单平均冒充数据源提供的板块指数。
- 未经确认的选项不视为已批准范围。
