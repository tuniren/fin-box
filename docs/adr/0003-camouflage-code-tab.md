# ADR-0003：自选工作台固定 Transformer 代码页

## 状态

已采纳

## 背景

自选工作台是应用启动后的首要工作界面，编辑区已经使用类似代码编辑器的标签页模型承载详情、K 线和分析页。新增需求要求该编辑区始终存在一个默认代码页，用于展示一份带语法高亮的 Transformer 核心示例代码，并在首次进入时优先呈现该页。

该能力需要满足以下约束：

- 标签标题固定为 `transformer.cpp`。
- 文件存储在配置目录下的 `camouflage/transformer.cpp`。
- 文件不存在时由主进程自动创建默认 C++ 内容；默认内容通过中文注释解释 Transformer 的核心计算原理。
- 固定标签永远位于第一个位置，不允许关闭。
- 代码页采用单界面展示，不拆分编辑区和预览区。
- 采用白色主题语法高亮。
- 不提供编辑功能，避免在无完整编辑器内核时模拟可编辑高亮层。
- 自选树单击仅改变选中项，不自动打开详情；详情标签仍由显式打开动作创建。
- 除自选工作台外，其他入口均保持单页路由，不显示左中右三栏。

## 决策

在自选工作台编辑区新增固定 `transformer.cpp` 标签，并将其作为初始激活视图。业务标签关闭后，如无其他可激活业务视图，则回退到 `transformer.cpp`。

文档读取由主进程 `AppCore` 提供固定 IPC。渲染进程不传入文件路径，主进程负责解析配置目录、创建 `camouflage` 子目录，并懒创建 `transformer.cpp`。

界面采用单一代码展示区。高亮层对预处理指令、关键字、类型、字符串、数字、注释和操作符做轻量词法着色；默认代码通过注释解释 token 向量、Q/K/V、缩放点积、softmax、上下文汇聚和前馈网络之间的关系。页面不提供编辑输入，以避免原生 `textarea` 与覆盖式高亮层之间的光标、选择、滚动和输入法同步问题。

## 结果

- 启动后默认可见 `transformer.cpp`，满足首屏代码化展示需求。
- 固定代码页不参与关闭、关闭其他、关闭右侧、关闭全部等业务标签操作。
- 文件路径由主进程封装，避免将任意路径写权限暴露给渲染进程。
- 其他页面继续作为单页路由呈现，不恢复左侧自选树或右侧详情辅助栏。

## 权衡

未引入 Monaco、CodeMirror 等完整代码编辑器，原因是该需求的核心是固定代码页和稳定展示。轻量词法高亮可以覆盖 C++ 示例代码的主要视觉结构，同时避免增加包体积、构建复杂度和编辑器状态同步风险。
